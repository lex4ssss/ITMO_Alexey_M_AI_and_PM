# Частые вопросы по работе с приложением

История заказов: раздел «Профиль» → «Мои заказы», фильтр по датам и статусу.
Чек по заказу выгружается кнопкой «Скачать чек» на карточке заказа.

Адрес доставки меняется в «Профиль» → «Адреса» до момента передачи заказа курьеру.
После передачи адрес меняет только оператор.

Двухфакторная аутентификация включается в «Профиль» → «Безопасность».
Поддерживаются коды по SMS и приложения-аутентификаторы.

Push-уведомления настраиваются в «Профиль» → «Уведомления»; ночной режим отключает
доставку сообщений с 22:00 до 9:00 по локальному времени устройства.

Статус заявки виден на карточке заявки; если статус не менялся более 48 часов,
обращение передаётся оператору.
